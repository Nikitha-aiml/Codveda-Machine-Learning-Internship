# 🟢 Level 1

## 1. Data Preprocessing

This task focuses on preparing raw data for machine learning by performing essential preprocessing and exploratory data analysis.

### Key Steps

* Data loading and inspection
* Exploratory Data Analysis (EDA)
* Missing-value analysis
* Duplicate-value checking
* Handling categorical variables
* Feature encoding
* Feature scaling
* Train-test splitting
* Saving processed datasets

### Outcome

The raw dataset was transformed into clean and processed datasets suitable for machine learning models.

---

## 2. Linear Regression

This task implements **Linear Regression** for predicting a continuous target variable.

### Key Steps

* Data exploration
* Data preprocessing
* Feature and target selection
* Train-test split
* Linear Regression model training
* Prediction
* Model evaluation
* Actual vs. predicted visualization

### Evaluation Metrics

* Mean Squared Error (MSE)
* R² Score

# 🟡 Level 2

## 3. Logistic Regression

This task implements **Logistic Regression** for binary classification.

### Key Steps

* Data preparation
* Feature and target selection
* Train-test splitting
* Logistic Regression model training
* Prediction
* Probability prediction
* Model evaluation
* Feature coefficient analysis
* ROC curve analysis

### Evaluation Metrics

* Accuracy
* Precision
* Recall
* F1 Score
* ROC-AUC

---

## 4. K-Means Clustering

This task applies **K-Means Clustering**, an unsupervised learning algorithm used to group similar observations into clusters.

### Key Steps

* Data preprocessing
* Feature selection
* Feature scaling
* Testing multiple values of K
* Silhouette Score evaluation
* Selecting an appropriate number of clusters
* Final K-Means model
* Cluster visualization

### Evaluation

The **Silhouette Score** was used to evaluate the quality of the generated clusters and help determine a suitable value of K.

# 🛠️ How to Run the Projects

### 1. Clone the repository

```bash
git clone https://github.com/Nikitha-aiml/Codveda-Machine-Learning-Internship.git
```

### 2. Navigate to the repository

```bash
cd Codveda-Machine-Learning-Internship
```

### 3. Install the required libraries

```bash
pip install numpy pandas matplotlib seaborn scikit-learn jupyter
```

### 4. Start Jupyter Notebook

```bash
jupyter notebook
```

Open the required task folder and run the corresponding notebook.
